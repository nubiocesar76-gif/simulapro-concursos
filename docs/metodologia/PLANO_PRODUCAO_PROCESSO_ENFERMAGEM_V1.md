# PLANO DE PRODUÇÃO EDITORIAL — PROCESSO DE ENFERMAGEM — V1

## Objetivo e status

Roteiro oficial de produção do banco de questões da disciplina "SAE — Sistematização da Assistência de Enfermagem" (nome de catálogo mantido; conceito normativo tratado como "Processo de Enfermagem", conforme `DOSSIE_MESTRE_PROCESSO_ENFERMAGEM_V2.md`). **Nenhuma questão é gerada neste documento** — é o planejamento que antecede a geração.

Base autorizada: `DOSSIE_MESTRE_SAE_V1.md` (histórico), `DOSSIE_MESTRE_SAE_INTELIGENCIA_EDITORIAL_V1.md`, `DOSSIE_MESTRE_SAE_AUDITORIA_NORMATIVA_V1.md`, `DOSSIE_MESTRE_PROCESSO_ENFERMAGEM_V2.md` (normativo vigente). Toda referência normativa deste plano usa exclusivamente normas vigentes (Resolução COFEN nº 736/2024, nº 754/2024, nº 564/2017, Lei nº 7.498/1986, Decreto nº 94.406/1987) — nenhuma norma revogada (272/2002, 358/2009, 429/2012, 311/2007) é usada como fundamento, apenas citada quando o próprio assunto é "tratamento de questão histórica".
